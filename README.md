# Tetris Auto

실행 파일: [dist/TetrisAuto.exe](dist/TetrisAuto.exe)

현재 실행·빌드 기준은 **루트 `src/`** 하나입니다. `release/`의 압축 해제본은 보존한 입력 자료이며
빌드에 사용하지 않습니다. 바이너리 관리 기준은
[배포 정책](docs/RELEASE_POLICY.md)을 참고하세요.

Windows 10/11 x64와 Chrome용입니다. EXE에는 Python과 GUI 라이브러리가 포함됩니다.
실행하면 공식 게임 https://play.tetris.com/ 을 별도 창으로 열고 영역을 반복 탐지합니다.
게임에서 **PLAY**를 누르세요. 자동 플레이 시작은 기본으로 꺼져 있으며 설정에서 켤 수 있습니다.

메인 화면에는 아래 두 줄만 표시합니다.

```text
게임찾기 | 실행(중지) | 끝내기 | 설정
보드: 정상   홀드: T   넥스트: L → T → O
```

**게임찾기**는 대상 창과 영역을 탐지합니다. **실행**을 누르고 준비 시간 안에 게임 창을
활성화하세요. 실행 중 버튼은 **중지**로 바뀝니다. **끝내기**는 키를 해제하고 종료합니다.
최소화된 트레이너는 작업 표시줄에서 다시 열 수 있습니다.

Auto 시작·중지는 **F6**, 긴급 중지는 **F8**입니다. NEXT 기본값은 1개이며 자동 탐지는 선택한 개수를 늘리지 않습니다.

실제 사이트에서 인식과 연속 입력 검증은 아직 완료되지 않았습니다.

메뉴가 격자를 가려도 중앙 보드 사각형과 양옆 HOLD·NEXT 패널이 함께 확인되면 영역 위치를 유지합니다. 일반 Auto는 일시적인 인식 끊김 동안 키를 해제하고 대기하며, 새 화면의 판독이 안정되면 이전 경로를 버리고 다시 탐색합니다. F8과 게임 창 포커스 상실은 계속 Auto를 중지합니다.

## 설정과 진단

설정은 Auto를 중지하고 별도 창으로 엽니다. 게임 창 선택, 영역 수정, 키·입력 시간,
진단 정보, 로그·캡처 저장, 개막 JSON 가져오기를 제공합니다. 좌표·탐색 정보·오류 코드는
메인에 노출하지 않습니다. 전체 traceback은 EXE 옆 `diagnostics/sessions/`에 기록합니다.

게임 기본 키는 방향키 이동, ↑ 시계 회전, Z 반시계 회전, C HOLD, Space 하드드롭입니다.
실제 게임 옵션에서 키를 바꿨다면 트레이너 설정에서도 맞추세요.
NEXT를 더 읽으려면 영역 수정에서 실제 슬롯 수를 지정하세요. 불확실한 슬롯은 `?`입니다.
기본 입력은 보수적인 35ms/35ms입니다. 설정의 빠른 입력값은 20ms/15ms이며 화면 확인은 유지합니다.
고정 지연은 현재 게임에서 직접 확인한 측정값만 사용하세요. 예측 점수 레벨은 계산용이며 실제 점수 OCR이 아닙니다.

## 전략과 검증 범위

도달 가능한 회전·이동·HOLD, 지형·구멍·높이 위험·입력 비용과 공개 점수표를 함께 평가합니다.
T스핀은 마지막 회전과 모서리 조건을 검사합니다. 남은 순서가 현재/HOLD/확인된 NEXT로 모두
설명되는 경우에만 구현된 TKI 변형을 선택합니다. PC를 찾지 못하면 일반 득점·안정화 탐색을 합니다.
시간·깊이·빔 폭 제한 안의 결과이며 전체 최적을 보장하지 않습니다.
미확인 콤보·PC 추가 보너스와 미니 점수는 다른 게임에서 가져오지 않았습니다.
현재 사이트의 T스핀 판정과 고정 규칙 일치는 실게임 미검증입니다.

[자료별 적용 범위](docs/STRATEGY_SOURCES_KO.md)를 확인하세요.

## 파일

- `dist/TetrisAuto.exe`: 최신 실행 파일
- `src/`: 프로그램 소스
- `data/`: 인식 기준 이미지, 오프너, 사이트 설정
- `tests/`: 테스트와 재현에 필요한 기준 캡처
- `tools/`: 빌드, 테스트, 인식 자료 가져오기 도구
- `docs/`: 사용법과 전략 설명
- `packaging/`: Windows 빌드 설정
- `.venv/`: 개발 및 빌드용 Python 환경

테스트: `.venv\Scripts\python.exe -m unittest discover -s tests -v`

빌드: `build_windows.bat`

설정의 **기본 제공 개막 빌드 선택**에서 TKI·스틱스핀·SDPC를 불러올 수 있습니다.
지원 구간과 사용 조건은 [개막 빌드 안내](docs/OPENERS_KO.md)를 참고하세요.

소스 실행·빌드에는 Tcl/Tk가 포함된 Windows Python이 필요합니다. 검증한 버전은 Python 3.12.14 x64입니다.
`run_windows.bat`은 필요한 경우 고정 의존성을 설치하고 실행합니다. `build_windows.bat`은 테스트·EXE 빌드·시작 검사를 수행합니다.

개인 설정은 `%USERPROFILE%\.tetris_trainer\`에 있습니다.
