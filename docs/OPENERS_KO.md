# 기본 제공 개막 빌드

사용자가 지정한 [테트리스 빌드 정리](https://hse30.tistory.com/73)의 상세 글을 참고한 빌드입니다.
배치 좌표를 직접 작성했으며 원문 이미지나 해법 묶음을 배포하지 않습니다.

| 선택 항목 | 지원 범위 | 참고 글 |
| --- | --- | --- |
| TKI / Fonzie | 기존 1가방, 명시된 순서 | 기존 JSON의 출처 정보 참고 |
| 스틱스핀 | 기본형 1~2가방, T스핀 싱글→더블, 좌우대칭 | [스틱스핀](https://hse30.tistory.com/1031) |
| SDPC | 왼쪽 O 기본형 및 PC 루트 1의 2가방, 싱글→더블, 좌우대칭 | [SDPC](https://hse30.tistory.com/483) |

설정 → **기본 제공 개막 빌드 선택** → 원하는 빌드를 불러옵니다.
불러오기만 하면 입력은 중지 상태이며 빌드 실행 설정은 꺼집니다.
기존의 프리뷰·기본 Auto 검증과 회전 확인이 모두 갖춰져야 설정에서 빌드 실행을 켤 수 있습니다.
선택한 빌드 이름과 출처는 불러오기 완료 정보에 보관됩니다.

새 빌드는 각 가방의 일곱 블록을 정해진 목표 칸에 놓습니다. 가능한 배치 순서는 미리 검사하고,
실행 때는 현재 보드가 검사한 중간 보드와 정확히 일치하는 경우에만 다음 배치를 고릅니다.
현재 블록을 우선 사용하며, 불가능하면 확인된 HOLD 또는 보이는 NEXT 첫 개로 한 번만 교환합니다.
보이지 않는 NEXT나 다음 가방 순서를 예측하지 않습니다. 향후 순서에 따라 도중에 중지될 수 있으며,
원문에 나온 모든 가방 순서·L/J 교환형·후속 분기를 지원한다는 의미가 아닙니다.

각 가방의 T스핀은 마지막에 수행합니다. 14개 배치 후에는 기존 빌드 완료 처리로 중지합니다.
SDPC의 3가방 PC, DPC, 스틱스핀의 트리플 및 후속 빌드는 이번 지원 범위에 포함되지 않습니다.
쓰레기 줄이나 보드 불일치가 있으면 중지하며 일반 Auto로 임의 전환하지 않습니다.
일반 Auto의 PC 목표와 기본 실행 방식은 그대로입니다.

새 JSON의 `order_status: stage-targets`는 1~3개의 `stages`를 받습니다.
각 단계는 7종 블록의 `targets`, 마지막 블록 `last_kind: T`, 삭제할 `lines`를 명시합니다.
컴파일러가 지지·겹침·SRS 경로·완성 가능 여부·T스핀·줄 삭제를 검사해 정확한 중간 보드별 선택지를 만듭니다.
기존 `order_status: explicit` 형식은 계속 지원합니다.

검증은 오프라인 모델과 모의 입력에 한정합니다. 실게임에서의 인식·입력·성공률은 미검증입니다.
