# 실게임 인식 기준 도형

`play.tetris.com`에서 직접 플레이하며 확인한 I·O·T·S·Z·J·L 캡처를 인식용 데이터로 가져왔습니다.

- `*_active.jpg`: 실제 전체 화면 원본. 이전 캡처 폴더의 원본을 복사했습니다.
- `*_piece.png`: 원본의 활성 도형을 격자 좌표로 잘라낸 참고 이미지.
- `templates.json`: 실제 도형 4칸 좌표, 촬영 색상의 색상각, 원본 SHA256, 보드·자르기 영역, SRS 회전 기준.

런타임은 이 JSON을 읽어 색을 구별하고 도형의 회전 후보를 검사합니다. 특히 실제 파란 J가 예전 기준에서 I로 오분류되던 경계를 보정합니다. 기준 JSON은 7종 완전성·SRS 모양 일치 여부를 검사하며, 형식이 손상됐으면 오류를 냅니다.

0/90/180/270도는 스폰 기준 시계 방향입니다. J·L·T는 네 모양이 다르지만, I·S·Z는 180도 간격으로 같은 모양이고 O는 네 방향이 같습니다. 한 장으로 같은 모양의 회전 이력을 확정할 수 없으므로 후보를 모두 표시합니다. 다른 방향들은 SRS 구조에서 유도한 것으로 실제 모든 방향을 촬영했다는 뜻이 아닙니다.

재가져오기: `.venv\Scripts\python.exe tools\import_piece_captures.py diagnostics\pieces_20261025`

검증은 실제 정지 캡처 + 주석으로 제공된 고정 보드, 실제 셀 사진을 사용해 만든 네 방향의 파생 테스트입니다. 움직이는 실게임에서의 연속 인식 성공률이나 모든 테마·배율·조명에 대한 정확도를 뜻하지 않습니다. 시작 시 중간 높이의 블록과 고정 블록을 구분할 이전 프레임이 없으면 기존처럼 대기할 수 있습니다.
